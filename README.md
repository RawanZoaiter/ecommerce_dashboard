# لوحة إدارة المتجر — E-Commerce Admin Dashboard

لوحة تحكم للمسؤولين، مبنية بـ Flutter Web، لمشروع مادة تطبيقات الإنترنت (الفصل الدراسي 2026).
تعرض المنتجات والطلبات والمخزون والمستخدمين والإشعارات، وتتصل بالـ REST API المبني بـ Laravel.

> **الحالة الحالية: واجهات فقط.** كل الشاشات تعمل على بيانات تجريبية داخل التطبيق، ولا يُرسَل أي
> طلب شبكة بعد. طبقة الاتصال بالـ API مكتوبة وجاهزة تحت `lib/core/network`، والتبديل إليها
> يحدث من مكان واحد (انظر [التبديل إلى الـ API](#التبديل-إلى-الـ-api)).

## التشغيل

```bash
flutter pub get
```

```bash
flutter run -d chrome
```

للتشغيل على منفذ ثابت (مفيد لو احتاج فريق الباك إضافة المصدر إلى إعدادات CORS):

```bash
flutter run -d chrome --web-port=5000
```

للعمل على شاشة معيّنة بدون تسجيل دخول بعد كل إعادة بناء (ولأخذ لقطات الشاشة):

```bash
flutter run -d chrome --dart-define=MOCK_SIGNED_IN=true
```

هذا المفتاح يُتجاهَل خارج وضع البيانات التجريبية، فما بينفع يتخطّى تسجيل دخول حقيقي أبدًا.

حساب الدخول في وضع البيانات التجريبية هو حساب المسؤول نفسه الموجود في دليل الواجهة
(`admin@example.com`)، وكلمة المرور معروضة على شاشة الدخول ما دام الوضع تجريبيًا.
الدخول بحساب زبون ممكن أيضًا، وتُرفض اللوحة برسالة خاصة — هذه الحالة مقصودة للاختبار.

إنه التبديل إلى الـ API الحقيقي ما بيلمس ولا widget.

## القرارات التقنية

**الأسعار أعداد صحيحة.** الدليل بيقول إن `price` نص بمنزلتين عشريتين، وما ينفع تُجرى عليه
عمليات بأرقام عشرية عائمة. `Money` بتخزّن القروش كـ `int`، فمجموع سطور الطلب دقيق تمامًا.
الاختبارات في `test/money_test.dart` بتغطي هذا.

**تجديد التوكن مرة واحدة فقط.** الدليل بيحذّر إن كل `refresh_token` يُستعمل مرة وحدة، وإنه
ممنوع إرسال أكثر من طلب تجديد بنفس اللحظة. `RefreshInterceptor` بيستعمل `QueuedInterceptor`
مع قفل واحد، وبيقارن التوكن المُرسَل بالمخزَّن قبل ما يجدّد، فطلب ثاني ما بيصرف تجديدًا زائدًا.

**`available_quantity` قيمتها `null` غامضة.** حسب تحديث المخزون، `null` معناها إما إن خدمة
المخزون متوقفة أو إن المنتج ما إله سجل مخزون. للزبون الحالتان سواء، أما للمسؤول فلأ. لهيك
التوفّر ممثَّل بـ `sealed class Availability` بأربع حالات، وكل حالة إلها نص خاص فيها.

**إخفاء الشاشات مش أمان.** حارس الدور بيخفي المسارات، بس كل شاشة كمان بتتعامل مع 403، لأن
الدور بينقرأ من قاعدة البيانات مع كل طلب وممكن يتغيّر والتطبيق مفتوح.

## نقاط مفتوحة

**نظام الأرقام في الواجهة العربية.** مكتبة `intl` بتكتب أرقام الـ `ar` بالأرقام اللاتينية
(`20`)، بينما بتكتب تواريخ الـ `ar` بالأرقام العربية-الهندية (`٢ نوفمبر ٢٠٢٦`). يعني الشاشة
الوحدة فيها النظامين مع بعض. الأسعار كمان لاتينية لأن `NumberFormat.currency` بتتصرف بنفس
الطريقة. التوحيد قرار منتَج مش تقني:

- الأسهل والأشيع بلوحات التحكم العربية: أرقام لاتينية بالكامل، ويتحوّل تنسيق التاريخ.
- البديل: أرقام عربية-هندية بالكامل، وبدها تحويل يدوي لكل رقم.

لم يُحسم بعد، وما في مكان واحد بالكود بيفرض أحدهما — كل التنسيق بيمرّ عبر
`core/utils/number_formatter.dart` و`core/utils/date_formatter.dart`.

**نصوص الإشعارات التجريبية بالإنجليزية.** لأن شكل الـ payload ما انحدّد بعد مع فريق الباك،
فنصوص العيّنة مكتوبة إنجليزي. بتتبدّل أول ما يوصل الشكل النهائي.

## التبديل إلى الـ API

```bash
flutter run -d chrome --dart-define=USE_LIVE_API=true
```

هذا بيرمي استثناءً واضحًا حاليًا، لأن تنفيذات الـ repository البعيدة لسا ما انكتبت. الخطوات:

1. اكتب `*RemoteDataSource` لكل وحدة فوق `ApiClient`.
2. اكتب `*RepositoryImpl` بتنفّذ نفس الواجهة الموجودة تحت `domain/repositories/`.
3. سجّلها في `lib/core/di/injector.dart` مكان رمي الاستثناء.

عنوان الـ API يتغيّر من مكان واحد كمان:

```bash
flutter run -d chrome --dart-define=API_BASE_URL=http://192.168.1.5:8080/api
```

## المطلوب من فريق الباك

الشاشات التالية جاهزة بالكامل وبتنتظر الـ endpoints، وكل وحدة فيها banner بيوضّح ذلك:

| ما هو مطلوب | لماذا |
|---|---|
| `available_quantity` في `GET /products` | عمود الكمية في جدول المنتجات، وعدّاد «مخزون منخفض» |
| مسار لارافيل لتعديل المخزون | المنتج المُضاف من اللوحة ما إله سجل مخزون، فما ينفع يُطلب |
| `inventory` في `GET /app-status` | للتمييز بين «الخدمة متوقفة» و«المنتج بلا سجل مخزون» |
| `GET /users` | وحدة المستخدمين من الوحدات الأربع المذكورة في المتطلبات |
| `GET /notifications` و`PATCH /notifications/{id}/read` | مذكورة في §7 من الدليل كمتفق عليها وغير منفّذة |
| `GET /admin/stats` | أرقام الصفحة الرئيسية بدل اشتقاقها من خمسة طلبات |

الواجهة لا تتصل بخدمة المخزون مباشرة أبدًا، فأي شيء يخص الكميات لازم يمرّ عبر لارافيل.
